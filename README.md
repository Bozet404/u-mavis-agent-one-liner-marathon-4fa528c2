# One-Liner Marathon

A program that writes a single one-line comedy joke to `/output/entry.txt`.

Run it with Node 22+:

```sh
node main.ts
```

It writes exactly one line — a setup with two disagreeing oracles and a
punchline that satisfies them both — and nothing else. No network, no
secrets, no dependencies.

Built for the [One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2) bounty on make.fun.
